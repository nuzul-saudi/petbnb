PETBNB — PERSONA & UX REVIEW · before / after

Finishing the persona system

The theme engine is sound — owner resolves to moss, host to honey + deep-gold with WCAG-AA-safe ink. But useTheme() is opt-in and almost nothing opts in, so host mode renders half-themed: the background flips to honey while host names, prices, ✓ marks and section pills stay hardcoded moss. Each frame shows the screen as built today beside the corrected version. Same persona wrapper — only the colour source changes.

As built — uses var(--moss-deep) directly
Fixed — uses var(--accent) (themes to gold)

Note the one deliberate constant: the verified ✓ stays moss in both — it's the brand trust mark, not a persona accent. Everything else should follow the lens.

1 · HOST HOME — index.tsx (HostHome) + ListingCard.jsx

The host's own home is the most mixed screen

AppShell flips the background to honey, but the section pill is hardcoded colors.moss and every card renders the host name + price in --moss-deep. The Button themes (it's the one opted-in component) so the CTA is already gold — which makes the moss around it look like a mistake.

Three calendars that disagree → one
